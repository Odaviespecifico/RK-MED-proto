# Frontend promovido à aplicação principal

O código ativo está em `src/`, os assets em `public/` e a configuração Vite na raiz. Execute `npm ci` e `npm run dev` na raiz do repositório. Esta pasta permanece apenas como referência histórica; não possui aplicação ou pacote independente.

Veja [desenvolvimento](../docs/desenvolvimento.md) e [acessos de demonstração](../docs/demonstracao.md). Arquivos locais ignorados antigos desta pasta não são lidos pela aplicação.
